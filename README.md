- # Ecommerce Turn System 📅

Appointment scheduling system for eCommerce with role-based login (managers and employees). Enables appointment assignment and visualization, as well as client and employee management.

## 🚀 Key Features

### Funcionalidades implementadas:
- 🔑 **Role-based Login** – Different access levels for managers and employees.  
- 📅 **Appointment Management** – Schedule, assign, and view appointments.  
- 👥 **Employee & Customer Management** – Add, modify, list, and remove records.  
- 💾 **Database Integration** – Centralized data storage to ensure consistency.  
- 📊 **Validation System** – Ensures correct scheduling and secure data handling.

## 🛠️ Tecnologías utilizadas

- **Backend**: C#, ASP.NET
- **Base de datos**: SQL Server
- **Frontend**: CSS
